A compact chess engine in 4 KB of Python: alpha-beta search with iterative deepening, a transposition table, killer and history move ordering, quiescence search, and a material plus piece-square evaluation. It plays the house gauntlet through the make.fun env at MAKEFUN_ENV_URL and scores by Elo.

## Run it

```sh
python3 main.py
```
